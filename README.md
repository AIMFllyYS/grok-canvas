# Grok Canvas

**简体中文** | [English](README.en.md)

**从创意到成片，把 Agent、导演台与无限画布放进同一个 AIGC 工作台。**

登录自己的 Grok 账号，从创作简报与素材生成导演脚本、固定参考图和精细动作分镜，再逐镜生成、验收并合成视频。也可以切换到无限画布自由连接素材，保留不同版本，继续尝试新的方向。

我一直想做一个自己的无限画布。借着 Grok 的图片与视频生成能力，把这个想法做成了一个可以实际创作的小工具，也希望让已有 Grok 订阅的朋友更方便地使用自己的可用额度。

> 个人开发的非官方项目，与 xAI / Grok 无隶属关系。当前为早期版本，供个人在电脑本地运行。作者已使用 Grok 订阅完成图片和视频生成；具体套餐覆盖范围尚未逐一验证。

## 可以做什么

- **Agent 与导演台**：默认进入 Agent 对话，使用 Vercel AI SDK 调用真实制作工具；导演台组织简报、完整脚本、固定参考图库、动作节拍、逐镜验收与 MP4 成片。
- **从素材到分镜**：上传图片、TXT/Markdown 或 MP4（抽取关键帧），检索并分析素材；中文阅读、英文生成、统一风格和负面提示词，支持 6 / 10 / 15 秒精细动作节拍。
- **精简工作区**：默认高级黑，右上角账户面板可切换米白、纸张主题。顶部只保留一条栏，导演台视图通过单个选择器切换；作品列表贴左边缘按需展开，可固定和调宽，镜头列表同样支持调宽。隐藏滚动条，保留正常滚动；导演台/Agent 支持窄屏使用。

- **图片生成与迭代**：文字生图、多图参考、提示词 `@` 引用当前画布的任意图片（含非主候选），一次生成 1 / 2 / 4 张候选图。
- **图片接着做视频**：文字生视频、首帧、尾帧和参考图，支持 6 / 10 / 15 秒及声音开关；已生成的视频节点可直接拖动画面移动，播放/进度/静音在底部控制条（悬停时显示）。
- **画布级素材库**：在右侧抽屉里可多选上传本地图片（画布上不再重复提供上传入口），生成结果也会自动登记；抽屉支持搜索和按已生成／导入／手动参考筛选，可把素材固定绑定到任意图片或视频节点；固定展开后也可以把图片直接拖进节点提示词输入框，效果与在输入框里用 `@` 引用这张图完全一致。
- **工具栏与主题**：选择（`V`）与手型（`H`）切换，按住空格临时平移；两种模式都能直接拖动节点，手型只是在空白处按住左键即平移（选择模式左键空白处是框选）；工具栏默认聚合在底部，可拖到自定义位置，也可在账户菜单拆散或重置；外观支持跟随系统、米白、高级黑和淡黄色纸张。
- **把过程留在画布上**：拖动、缩放、连线、多画布管理；已有图片再次生成时保留原图，在新节点继续。
- **结果保存在本机**：素材、画布和生成记录落盘，可以查看生成参数并下载结果；视频任务保存状态以便恢复查询。

## 先了解账号与额度

工作台的完整流程、架构、数据恢复与验收说明见 [AIGC 工作台文档](docs/aigc-workstation.md)。完整 MP4 合成和视频素材关键帧需要本机安装 **FFmpeg**，也可设置 `FFMPEG_PATH`。当前合成为无声画面版，旁白、配乐、字幕单独后期处理。

项目通过 xAI OAuth 登录，不需要在项目里填写 API Key。目前使用 Grok Build 的 OAuth 客户端，**授权页会显示 Grok Build**，这是当前接入方式，并非 Grok Canvas 的独立官方授权客户端。该第三方接入的长期可用性与分发许可尚未获得单独确认，按实验性接入提供。

使用你自己的 Grok 账号额度，作者已通过 Grok 订阅验证图片和视频生成。具体可用功能与额度以账号实际情况为准，详情见 [Grok 官方说明](https://docs.x.ai/grok/faq)。

登录后账户菜单会只读显示 **Grok 共享额度 · 已用 xx%**。它读取的是与你账号 Grok CLI `/usage` 同一额度池的数据，**不是本画布用量，也不是图片／视频各自的剩余次数**。该接口并非官方承诺的稳定 API，读取失败时只显示“暂不可用”，不会用本项目的生成次数或费用估算替代百分比。

## 快速开始

需要 **Git、Node.js 22.18+ 和 pnpm 10.33.2**。仓库用 `.nvmrc` 固定了已验证的 Node.js 22.22.2；使用 nvm 时可先运行 `nvm install` 和 `nvm use`。

如果尚未安装 pnpm：

```sh
npm install -g pnpm@10.33.2
```

下载、安装并启动：

```sh
git clone https://github.com/wangxiaosu/grok-canvas.git
cd grok-canvas
pnpm install --frozen-lockfile
pnpm dev
```

在电脑浏览器访问 **[http://127.0.0.1:3210](http://127.0.0.1:3210)**。默认无需 `.env` 配置。

1. 点击右上角登录，在 xAI 授权页登录自己的账号并完成授权。
2. 返回工作台，确认右上角显示头像和名称（名称取邮箱 `@` 前的部分）。若未自动返回，可通过登录浮层粘贴授权码完成；登录等待超过 10 分钟需重新发起。
3. 在默认 Agent 对话中描述创意，或打开导演台填写简报、上传素材并生成完整脚本。
4. 在参考图库生成固定素材，在分镜制作中检查动作节拍并生成图片、视频；可以逐项操作，也可以使用自主制作补齐缺失产物。
5. 验收镜头后合成并下载完整 MP4。切换到画布可自由连线、添加图片／视频节点；右侧素材抽屉、附件和 `@` 引用继续可用。项目与画布保存在本机，下次启动可以继续。

停止服务时在终端按 `Ctrl+C`。日常使用也可以构建后启动：

```sh
pnpm build
pnpm start
```

`dev` 和 `start` 都使用本机 3210 端口，只运行其中一个。不要同时启动两个实例，也不要在已有开发服务运行时原地构建；检查生产构建可使用独立工作目录。

## 桌面版

Windows 安装包发布在 [Releases](https://github.com/AIMFllyYS/grok-canvas/releases)。安装后不需要另外安装 Node.js，也不需要手动启动终端服务；数据和浏览器版共用 `~/.grok-canvas` 目录。

从源码打包：

```sh
pnpm install --frozen-lockfile
pnpm desktop:build
```

安装包会输出到 `release/`。桌面版和开发服务都使用 3210 端口，打包前需要先停止正在运行的开发服务。目前安装包没有代码签名，Windows SmartScreen 可能提示未知发布者。

## 使用边界与常见问题

| 情况 | 说明 |
| --- | --- |
| 手机能否使用 | Agent 和导演台支持手机布局；自由画布需要电脑、鼠标和键盘，最低窗口为 1100 × 640，推荐 1440 × 900。 |
| 登录后仍无法生成 | 登录成功不等于拥有模型权限。检查账号用量、套餐权限和服务端错误；认证过期时重新登录。 |
| 提示额度不足或限流 | 以 Grok 账号页面为准，等待额度恢复或按官方提示处理。重试生成可能再次消耗额度。 |
| 在哪里查看剩余额度 | 账户菜单显示 Grok 共享额度，可与同账号 Grok CLI `/usage` 对照；接口不可用时显示“暂不可用”，不提供估算。 |
| 素材库只看得到本画布的图片 | 素材库按画布绑定，切换画布即切换到该画布自己的素材；新画布不会继承其他画布的素材。 |
| 手型模式和选择模式有什么区别 | 只有一个：空白处按住左键，手型是平移画布，选择是框选。节点上的点击、选中、编辑面板、拖拽移动、连线两种模式完全一样。 |
| 上传或生成过程中切换画布 | 会先完成本画布的导入与保存再切换；刷新或关闭页面前浏览器会提示尚未完成的工作。 |
| 端口占用 / 页面 403 | 使用 `127.0.0.1:3210` 或 `localhost:3210`；当前访问校验与 OAuth 回调固定使用此端口，不支持任意换端口或域名。 |
| 图片上传失败 | 支持 PNG / JPEG / WebP，单张最多 20 MB；图片生成最多使用 5 张参考图。 |
| 视频不能选择 1080p | 带尾帧或参考图时最高 720p；仅首帧时比例跟随首帧。视频参考图最多 7 张。 |
| 视频完成但下载失败 | 保留任务记录，可重试保存；若上游临时链接已失效，需要重新生成。 |
| 关闭页面或服务 | 已保存的画布和素材保留；视频已保存的任务可恢复查询。图片生成期间建议保持页面和本地服务开启。 |
| 想部署到服务器 | 当前是单用户本机服务，没有多用户隔离，不支持直接公开部署或通过隧道开放给他人。 |

## 数据与隐私

默认存储位置（`~` 表示当前用户目录）：

```text
~/.grok-canvas/
  auth.json              # OAuth 登录凭据
  data/
    app-state.json       # 最近使用的画布
    canvases/            # 画布、节点、连线和画布内素材目录
    assets/              # 上传及生成的图片、视频
    generations/         # 与素材绑定的生成记录
    video-tasks/         # 视频请求和任务状态
```

生成记录保存原始提示词、实际提交提示词、模型、参数及参考图顺序，不会被后续编辑画布覆盖。上传素材和没有记录的旧素材不会凭空补出生成历史。删除画布不会同时删除素材文件。

素材目录随画布文件保存，记录素材名、显示名称和入库来源；图片文件由多个画布共享，但目录归属严格跟随当前画布。删除节点不会删除已登记的素材，本次也不提供素材物理删除。

生成请求由本机服务发送到 xAI，包含提示词和参与生成的参考图；生成结果从上游下载到本机。本地保存不等于离线生成。

需要备份作品时，停止服务后复制整个 `data` 目录。`auth.json` 包含敏感登录凭据，不要上传到 GitHub、发到 Issue 或作为作品备份分享。退出登录会清除本项目本地凭据，不等同于撤销账号侧的授权，也不会删除作品。

需要自定义存储位置时，把 [`.env.example`](.env.example) 复制为 `.env.local`，按注释设置绝对路径并重启服务。已有数据不会自动迁移到新路径。

## 开发与反馈

技术栈：Next.js、React、TypeScript、React Flow、Tailwind CSS。

```sh
pnpm typecheck
pnpm test
pnpm build
```

`pnpm check` 按顺序执行以上检查。自动化测试使用模拟请求，不需要登录或消耗 Grok 额度。欢迎通过 Issue 或 Pull Request 参与改进。

第一次体验时，欢迎在 [Issues](https://github.com/wangxiaosu/grok-canvas/issues) 反馈：安装是否顺利、图片与视频是否可用、创作过程中最卡在哪一步。请提供系统、Node.js 版本、操作步骤及脱敏后的报错；不要粘贴登录凭据。涉及安全问题时，请先联系维护者获取私密反馈渠道，不要在公开 Issue 发布漏洞细节。
