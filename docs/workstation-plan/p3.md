# P3 SQLite、迁移与可靠增量同步

本阶段不是把CanvasDoc作为一行JSON插入数据库。三端闸门、备份和outbox排空都是主库切换的硬依赖；任何失败不得自动回退驱动、降低同步安全或跳过坏文件。

- worker.cjs是可直接随包运行入口；内部服务端私有文件不被浏览器import。

### Do
1. 先写临时DB健康检查/建表/事务回滚/关闭重开/Worker退出用例；缺少驱动时明确失败，不skip。
2. 核对待选精确包版本支持Node最低线与Electron目标，记录实际sqlite_version；禁止只看npm包名判断安全。
3. 安装默认ignore-scripts，只对该native包执行受控构建；不重写整个lockfile或升级Next/React。
4. driver设置C4 PRAGMA，读取并返回实际值；SQLite<3.51.3或配置不符则health不通过。
5. service按canonical dataDir保存globalThis单例；requestId关联请求，超时/崩溃清理回调；限128条/16MiB/4MiB。
6. worker只接受固定op，不允许用户提交任意SQL。health返回版本/路径/队列；tests专用建表通过内部测试repository。
7. 两个route模块同时调用只启动一个Worker；重启需明确状态转换，未确认命令交由原ID恢复查询。
8. 添加Node22与24的CI测试入口，关闭时释放连接/线程，不遗留句柄阻止测试退出。
