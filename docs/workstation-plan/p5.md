# P5 Agent进度、预显示与大图工具

工具执行与媒体呈现是两套状态，来源共享但不能混淆。只展示真实工具事件，不伪造模型内部推理。所有测试使用mock模型/上游，不产生真实生成费用。

## P5-01 持久工具状态机、真实事件与SDK流桥接

### Plan
- 目标：工具卡片/画布共享实际执行状态，可在重启后辨别已提交、失败或unknown。
- 当前：SDK工具卡片只有粗粒度运行/完成；P2最小预显示已有，P3有tool_calls/task_runs。
- 阅读：`lib/agent/agent.ts`、chat route、`components/ai-elements/tool.tsx`、安装版ai的UI data stream类型、contracts C6/C8。
- 新增：`lib/agent/events.ts`、`execution.ts`、`tests/agent-events.test.mjs`。
- 修改：Agent工具execute包装器、chat route、tool卡片；登记test:agent-runtime。
- API：`transitionTool(identity,next,details)`验证合法状态迁移；`emitToolEvent(event)`只发已确认阶段，不访问模型内部思考。

### Do
1. 测试input-streaming→validating→queued→executing→committed及blocked/failed/cancelled/unknown分支。
2. 执行包装器在真实校验/排队/DB提交边界发阶段，completed/total仅来自实际处理数。
3. 终态/关键阶段持久到tool_calls，使用run/tool独立eventSeq；committed只能由命令receipt触发。
4. 通过当前SDK支持的data-*或transient桥接UI流，保留原文本/reasoning/工具结果，不更改协议终止帧。
5. 无总量显示阶段和耗时，不显示猜测百分比；视频提交成功写“已提交任务”，不写“视频生成完成”。
6. 事件发布失败不回滚已提交命令，客户端从持久记录恢复；数据库失败不能先发committed。
7. 更新工具卡片中实际操作目标ID/定位按钮，避免输出整个canvas或大段参数重复撑UI。

### Check
- `node --test tests/agent-events.test.mjs tests/agent-sdk.test.mjs tests/db-commands.test.mjs`。
- 非法回退如committed→executing拒绝；重复终态不重复渲染/写记录。
- 命令失败无committed；发布失败后读持久记录仍committed且实体只存在一次。
- 无total时不存在百分比字段；partial计数不超过total；工具阶段与canvas eventSeq不混用。
- UI流正常结束/取消/异常不丢工具配对；typecheck/test/build。

### Act
- 交接完整状态转移表、事件schema和SDK桥接实际类型，给P5-02/04消费。
- 不调用真实模型测试，不把transient事件当唯一持久事实。

### Do

2. 仅消费SDK已解析partial对象的完整字段；不逐token对整JSON正则重解析，不推测尚未存在的节点数量。

## P5-03 大图摘要、分页检索、邻域与正文分块工具

### Plan
- 目标：不再把整个画布交给模型，所有查询同时限制条数/字符/字节。
- 当前：read_canvas返回完整图；context可能汇总完整消息/节点信息；SQL实体查询可用。
- 阅读：`lib/agent/agent.ts`、`canvas.ts`、`context.ts`、SQL repositories、contracts C5/C8。
- 新增：`lib/agent/canvas-queries.ts`、`query-cursor.ts`、`tests/agent-canvas-queries.test.mjs`。
- 修改：工具定义与系统提示中的读图指南、repository必要索引，不改变模型选择/收费接口。
- 工具：read_canvas/get_canvas_nodes/search_canvas_nodes/read_canvas_neighborhood/read_document_chunk。

### Do
1. 建10000节点/20000边/中文短词/100KB正文fixture，测试摘要大小、分页、错canvas和坏cursor。
2. read_canvas返回revision、类型计数和最多50摘要；不含正文/claims/消息全集。
3. get按ID最多50、正文总32000字符；read_document_chunk每段16000并返回documentVersion/start/nextCursor。
4. search名称规范化contains+类型/区域过滤，参数化SQL；中文1/2字词能返回预期结果，不假设FTS默认分词。
5. neighborhood按source/target索引，方向/limit明确，不将高出度节点全部边返回。
6. 编码cursor含canvas/queryHash/revision/sortKey；错误400，revision变更返回restart提示，不默默跳页。
7. 在构造结果时执行64KiB上限，返回合法truncated/cursor，不序列化后剪字符串破坏JSON。
8. 调整Agent提示说明先摘要→局部查询→命令；保留20/30/40批次与并发1/12步限制。

### Check
- `node --test tests/agent-canvas-queries.test.mjs tests/agent.test.mjs tests/agent-sdk.test.mjs`。
- 万级read_canvas响应≤64KiB且无长正文；详情不超过条数和字符预算。
- 中文“图”“分镜”能检索；SQL注入文本当字面查询；伪cursor和跨画布cursor拒绝。
- 分页在固定revision无遗漏/重复；revision变化明确重启；邻域高出度仍有界。
- 模型工具描述不再要求先读取全图；typecheck/test。

### Act
- 提供工具输入/输出样例、游标错误表和真实响应字节数，后续Agent照此调用。
- 不引入向量库、外部搜索服务或重新研究数据库选型。

- 当前：视频有requestId恢复，图片有generation记录与claim；新事件/preview已实现但需集成故障验证。
- 阅读：video-runtime/tasks、generation-claims、Agent controller/chat route、contracts C3/C6/C8。

- 修改：Agent执行包装器、恢复入口、面板取消反馈；不更换上游客户端。

### Do
1. 模拟提交前取消、提交后断网、DB已commit但流断开、上游完成但下载失败、用户切画布/删节点。
2. 分离cancel_requested/cancelled/unknown；只有上游明确确认取消或尚未提交才标cancelled。
3. 有requestId按原ID查询；只有remoteUrl时重试下载；两者都不确定时保持unknown并提示人工，禁止新POST生成。
4. 重启读取tool_calls/task_runs/claims恢复UI和查询，不恢复过期临时预览，不重复分配实体ID。
5. 跨canvas后台控制器持续保存原归属，隐藏面板不重绘；原画布删除只留恢复记录，不重建。
6. 同字段冲突显示blocked原因和安全重试入口，用户确认后重新读取版本/生成新编辑命令；收费未知任务仍不重发。
