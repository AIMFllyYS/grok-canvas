# P4 万级显示与媒体资源预算

保留React Flow近景交互，Canvas2D只承担远景概览。裁剪不等于删除，预览不等于正式节点，视频提交成功不等于可播放。所有预算从runtime-budget读取。

## P4-01 资产Range、HEAD与流式响应

### Plan
- 目标：大视频不再通过readFile整文件加载；保留路径和同源安全校验。
- 当前：`app/api/assets/[name]/route.ts`读取整个文件响应；`lib/assets.ts`定义安全名称和MIME。
- 阅读：资产路由、assets、local-access/proxy、contracts C7。
- 新增：`lib/media/range.ts`、`asset-stream.ts`、`tests/asset-range.test.mjs`。
- 修改：资产GET/HEAD路由，package.json登记test:media。不要更改收费生成/下载接口。
- API：`parseSingleRange(header,size)`返回full/partial/unsatisfiable；`streamAsset(path,range,signal)`保证关闭句柄。

### Do
1. 对1000字节文件写range矩阵：无头、0-0、100-、-100、999-999、1000-、100-50、多range、非数字。
2. 纯解析函数不触碰文件；size/offset安全整数校验，416带bytes */size。
3. GET使用createReadStream并转换Web流，合法范围206，完整200；Content-Length准确。
4. HEAD复用metadata和range决策但绝不创建body流。
5. request.abort/reader.cancel关闭流和fd；文件删除/读取错误映射404/500，不把截断内容标200完整成功。
6. 保留isSafeAssetName/assetPath、Content-Type与同源保护，不允许任意绝对路径下载。
7. 设置缓存与ETag以资产不可变内容为依据，If-Range不匹配时返回完整200；不根据用户可变node状态生成ETag。

### Check
- `node --test tests/asset-range.test.mjs tests/local-access.test.mjs`。
- 0-0返回1字节、Content-Range bytes 0-0/1000；-100返回最后100字节。
- 越界/反向/多range明确416；HEAD body为空但长度正确。
- 读取临时大文件时不调用readFile；中断后句柄可释放，Windows可重新打开/重命名测试文件。
- 路径穿越/伪造name拒绝；typecheck/test/build。

### Act
- 交接请求/响应矩阵和流取消证据；不以服务单元测试宣称播放器兼容已验收。

- 修改：资产派生查询路由、上传/结果落盘后排队接点、package.json。派生处理固定用sharp，显式依赖锁定现有lockfile已有的0.35.4，执行`pnpm add sharp@0.35.4 --save-exact --ignore-scripts`；纳入三端native验证，不另选处理库或升级其他包。
- 接口：`requestDerivative(assetName,variant)`返回pending/ready/failed和稳定URL；同sourceHash+variant去重。

### Do

## P4-03 统一媒体调度、缓存与播放器租约

### Plan
- 目标：节点、素材库、候选和工具结果共享下载/解码预算；离屏不继续占用播放器。

- 新增：`lib/media/loader.ts`、`cache.ts`、`player-leases.ts`、`tests/media-budget.test.mjs`。
- 修改：上述媒体调用点；保留已有素材库每页40项，不另重做分页。
- API：`acquireMedia(key,priority,signal)`返回handle和release；`acquirePlayer(nodeId)`受全局2实例/1主动播放限制。

### Do
1. 用可控fetch/decode计数测100订阅、去重、abort、最后订阅者退出、LRU驱逐。
2. 网络6、主动解码2，优先当前编辑/可视资源，预取最低；解码完成再检查是否仍有订阅者。
3. 缓存按128MiB与3200万像素双阈值驱逐；关闭ImageBitmap、revokeObjectURL，释放不是仅Map.delete。
4. 所有展示消费thumb256/1024，用户详情才原图；工具结果图片也接同服务。
5. 视频默认poster，主动点击拿播放器lease；第三个请求提示资源占用或释放最旧暂停实例，不同时挂三个video。
6. 离屏/隐藏暂停并卸载src/调用load释放解码；租约释放幂等，返回视口不自动全部播放。
7. 取消预取只取消对应消费者；不得取消生成任务、另一个组件共享下载或用户主动播放。

### Check

- 100同key只有1fetch；取消其中99不影响最后1；全部取消后释放底层资源。
- 冷热缓存分别统计；失败可重试不产生无限循环；用户切canvas释放不再需要的资源。
